# CodeManu Free VFX Asset Pack

Selected runtime effects from the [CodeManu Free VFX Asset Pack](https://codemanu.itch.io/vfx-free-pack):

- `small-hit.gif` -- Effect_SmallHit, 30 fps
- `big-hit.gif` -- Effect_BigHit, 30 fps
- `electric-shield.gif` -- Effect_ElectricShield, 30 fps
- `anima-death.gif` -- Effect_Anima, 30 fps
- `stagger-stars.gif` -- Effect_PuffAndStars, 30 fps (Whale charge interruption)
- `breach-wheel.gif` -- Effect_Wheel, 60 fps (Whale breach/spawn ring)

The author describes the pack as public domain and free for personal and commercial use without required credit. The itch.io metadata currently lists Creative Commons Attribution 4.0, so Degen Tactics retains this attribution conservatively.

Only the selected runtime assets are shipped. The 96 MB source pack is intentionally excluded from version control.
