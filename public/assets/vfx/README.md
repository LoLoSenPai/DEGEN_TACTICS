# CodeManu Free VFX Asset Pack

Selected 30 fps effects from the [CodeManu Free VFX Asset Pack](https://codemanu.itch.io/vfx-free-pack):

- `small-hit.gif` — Effect_SmallHit
- `big-hit.gif` — Effect_BigHit
- `electric-shield.gif` — Effect_ElectricShield
- `anima-death.gif` — Effect_Anima

The author describes the pack as public domain and free for personal and commercial use without required credit. The itch.io metadata currently lists Creative Commons Attribution 4.0, so Degen Tactics retains this attribution conservatively.

Only the selected runtime assets are shipped. The 96 MB source pack is intentionally excluded from version control.
